# 比特球云下载接入

本分支基于主分支 `f16b903daf07da917b3184d61367519ac0fa0fe7`，生产基线保持 v19。仅在 `bitqiu-cloud-download` 开发和检查，不合并主分支、不发布镜像。

## 首版边界

- 复用 Bitqiu 驱动已验证的登录会话和持久设备标识，不新增固定 UUID、不因查询或重试主动发送短信。
- 在 AList 离线下载框架中增加 BitQiu 工具；只接受经客户端接口证据确认支持的链接类型。
- 选择已有 Bitqiu 文件夹，由比特球服务器直接保存；不创建 NAS 下载、不走本地中转、不自动上传或创建远端目录。
- 查询远端任务状态、进度、失败原因，完成后刷新相应目录缓存。
- 本地任务、远端任务 ID、创建者、存储及目标目录关联持久化；容器重启优先恢复查询，不重新提交同一链接。
- 创建请求若响应丢失，标记“提交结果待确认”，不得盲目自动重试造成重复任务。
- 用户和路径权限检查贯穿创建、查询和恢复，不能向其他用户暴露同账号云任务。
- 暂停、恢复、取消、删除、BT 内文件选择、批量操作、自动下载到 NAS 不属于未验证即可开放的能力。取消只有确认真实远端停止接口后再开放。

## 接口证据门槛

当前驱动 `drivers/bitqiu` 只有文件列表、链接和常规文件操作，没有云任务创建/查询实现。已有 Windows 登录接口和签名不能替代云任务协议验证。

需要从官方客户端或经过脱敏的实际请求确认：请求路径、HTTP 方法、鉴权/签名字段、链接类型、目标目录参数、任务 ID、分页方式、进度口径、成功/失败/未知状态和会员/配额错误。没有证据的字段和接口不能猜测后启用。

此前上传的 Windows 安装包分块当前无法重新读取，原始 SHA256 为 `57c5d6970920ffcfc3f6b3f323327080be60676940b41daa7b43acd97129bff2`。正在请求可用的官方安装包来源；此阶段未对真实账号提交任务或消耗云下载配额。

## 框架注意事项

现有离线下载 `Tool` 接口提供 AddURL/Status/Remove/Run；网盘工具须同时加入远端保存路径和完成分流，避免被当成本地临时目录处理。

现有 `DownloadTask.GID` 为 `json:"-"`，且通用 Run 会调用 AddURL；不能直接据此承诺重启后安全恢复。Bitqiu 接入必须使用持久远端身份和提交状态保护，并覆盖创建超时、重启与重试的重复提交回归。

未验证取消时，也不能套用其他工具“只停止本地跟踪、云端继续”的 Remove 行为并显示“云端已取消”。
