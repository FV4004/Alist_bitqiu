# NAS 单向补缺测试分支

分支：`nas-management-compare-preview`。版本：`v3.65.0-bitqiu.20-preview`。

本次仅测试分支构建，不合并 main、不推送 Docker Hub/GHCR、不创建 Release。生产 `latest` 保持 v19。工作流 `.github/workflows/nas-compare-preview.yml` 仅具有 `contents: read`，无仓库登录、推送及发布步骤。成功后在 Actions Artifacts 保存 `alist-bitqiu-compare-linux-amd64`，包含镜像、二进制、SHA256SUMS 和 COMMIT；保留 30 天。

## 导入与回退

下载构建产物 ZIP，解压后校验 `SHA256SUMS`，在极空间 Docker 镜像导入界面选择 `alist-bitqiu-compare-linux-amd64-image.tar.gz`；如导入器仅支持 tar，先解压一层 gzip。镜像标签为 `alist-bitqiu:compare-<提交前12位>`。停止原容器后，使用新镜像并保留原 `/opt/alist/data` 与 `/downloads` 挂载。无需数据库迁移；已入队任务仍使用原任务记录格式，可回退到 v19。不要同时让两个容器写同一份数据目录。

## 统一排序

排序在搜索下方，支持名称/修改时间/文件大小升降序，独立选择应用于网盘和 NAS，默认同时应用，可勾选文件夹优先。未应用时网盘恢复原修改时间倒序，NAS 恢复文件夹优先、名称升序。未知容量（包括未统计的文件夹）不按 0 字节排序，始终在同组已知容量之后。缓存返回采用当前排序，不恢复旧目录的排序条件。只在本地排序，不增加目录 API 调用。

## 单向补缺流程

1. 选择网盘来源根目录与 NAS 目标根目录，点击“扫描缺失项目”。扫描不受顶部显示筛选限制，只读取，不创建下载任务。
2. 按相对路径和类型递归比较。NAS 同路径文件存在即跳过，不比较内容、不按大小或时间替换；NAS 多出的文件保持原样。
3. 结果分为“缺失文件”“缺失文件夹”“待核对缺失项”。每页签只显示当前结果分类；默认均不勾选，支持当前分类全选、逐项选择、跨分类保留选择。文件夹可展开查看内部缺失项。每次显示 200 项，支持继续显示。
4. 疑似改名仅根据同级 NAS 名称提供候选，最多检查该目录前 512 个对象、最多显示 5 个候选，不推断内容相同，不进行全盘跨目录内容去重。候选规则包括大小写/全半角、分隔符及有限的字符差异，数字序列及扩展名不一致不会按相似文件处理。疑似项须明确勾选；选择普通缺失文件夹不自动确认其内部疑似项。
5. 无法读取、类型冲突、链接或目录循环显示在独立“扫描问题”区域，不当作缺失。未完整扫描的文件夹禁止整体选择；其他已确认缺失文件可单独选择。
6. 点击“生成去重清单”：服务端展开选择、按完整目标路径合并父文件夹/子文件重复选择，再跳过已出现的 NAS 对象和已有等待/运行/暂停/失败任务。不同目录同名文件保留。大小写或全半角路径可能冲突时阻止整批，需单独复核选择。
7. 最终页显示来源、目标、文件/文件夹数、已知容量与未知容量数、每项相对路径、跳过原因。必须勾选“已人工核对”并点击“确认下载到 NAS”才入队；返回复核或关闭窗口不入队。
8. 确认时再次检查目标存在和已有任务。实际写入使用原防覆盖机制；若外部程序在实际传输过程中抢先创建同名文件，该任务会安全失败而不覆盖，用户可重新扫描。空目录也创建；所有任务复用原复制引擎、并发上限、暂停/恢复/取消和文件夹分组。

## 扫描与确认限制

扫描支持进度、取消与断流检测，完整结果到达前不可提交。串行访问目录并在目录间等待 150ms；全局最多同时 2 次扫描，每次最长 10 分钟，最多 50000 项/128 层。源驱动单目录分页仍使用现有 BitQiu 节流与完整性检查。失败、取消或断流不会产生可提交快照。

扫描快照及确认清单仅存于服务器内存，归属创建用户，有效期 15 分钟，最多各 8 份、总计各 200000 项。重启、过期后需重新扫描；已确认入队的任务正常持久化。最终页去重后条目不超过扫描条目数，现有文件不覆盖、不删除，无上传功能。

## 验收

- 后端真实目录：只报告缺失；同路径不同大小文件不替换；文件夹/叶子重叠选择去重；同级疑似名进入人工核对；数字不同保持不同；空目录创建。
- 失败与安全：读取失败不误判；链接、类型冲突、循环、大小写路径冲突阻止；归属及管理员权限校验；扫描/预检查不入队；未确认拒绝；重复提交拒绝。
- 最终竞争：扫描后出现目标、已有暂停任务、确认时新出现文件均跳过；真实复制后旧内容保持。
- 浏览器：Chromium/WebKit、根路径/前缀、移动布局；排序应用范围/未知大小；选项卡隔离、疑似项默认不选、最终清单及手动确认、防双击提交、扫描取消/失败/断流。原登录、NAS 任务及流式目录回归保留。

实际通过记录见本分支 Actions；极空间实机需导入后验证。
