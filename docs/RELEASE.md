本版本 v3.65.0-bitqiu.20 在 AList 基础上更新 Bitqiu NAS 功能：

- 统一双侧排序，可分别应用于网盘与 NAS。
- 按左侧勾选的文件/文件夹启动后台缺失扫描；离开或刷新页面继续运行。
- 统计范围时展示数量，NAS 核对时展示百分比；支持取消，重启后明确提示中断。
- 显示上次完整扫描时间，同范围扫描未完成时保留最近完整结果缓存。
- 缺失文件/文件夹/待核对项独立选项卡，生成去重清单并人工确认后下载。
- 网盘目录流新条目追加到末尾，保留已选项，显示加载进度，手动触发重新排序。

复用原下载队列和并发控制，无数据库表结构、配置或 Docker 挂载迁移。扫描元数据保存在现有 AList 数据库，随数据目录持久化；旧镜像回退不受影响。使用规则见 docs/NAS_BACKGROUND_SCAN.md。
